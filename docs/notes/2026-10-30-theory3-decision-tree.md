## 2. 로지스틱 회귀는 과소적합인가

```python
lr = LogisticRegression()
lr.fit(train_scaled, train_target)   # 훈련 0.7808, 테스트 0.7777
print(lr.coef_, lr.intercept_)       # [[0.5127 1.6734 -0.6878]] [1.8177]
```

- 두 점수 차이가 작아 과대적합 징후는 약하다. 훈련 점수 자체가 낮아 과소적합을 **의심**할 수 있다.
- 강의 강조점: **확신 말고 의심하기.** 현상을 보면 가설을 세우고, 다른 모델이나 실험으로 확인한 뒤 판단한다.

### 과소적합은 상대적인 개념이다

절대 기준은 없고, 이 데이터에서 도달할 수 있는 성능과 비교해 판단한다. 같은 분할로 비교한 결과:

| 모델 | 훈련 | 테스트 |
|---|---|---|
| 다수 클래스 기준선 (무조건 화이트) | 0.7579 | 0.7377 |
| 로지스틱 회귀 (교재) | 0.7808 | 0.7777 |
| 로지스틱 회귀, C=1000 | 0.7803 | 0.7777 |
| 로지스틱 회귀 + 2차 특성 | 0.8051 | 0.7954 |
| 로지스틱 회귀 + 3차 특성 | 0.8211 | 0.8131 |
| 결정 트리, 깊이 3 | 0.8455 | 0.8415 |
| 결정 트리, 제한 없음 | 0.9969 | 0.8585 |

1. 기준선보다 훈련 점수가 2.3%p밖에 높지 않다. 숫자만 보면 그럴듯하지만 패턴을 거의 잡지 못했다.
2. 규제를 거의 없애도(C=1000) 그대로다. 원인은 규제가 아니라 **표현력**이다.
3. 다항 특성으로 표현력을 늘리자 **훈련·테스트 점수가 함께 올랐다**. 과소적합의 전형적인 신호다.
4. 단순한 트리(깊이 3)도 테스트가 6%p 이상 높다. 직선 하나로는 표현할 수 없는 구조가 있다.

- 결론: 이 데이터, 이 특성 세 개 기준으로 **상대적 과소적합**이다. 빠진 특성이 있다면 어떤 모델이든 막히는 한계는 데이터의 한계다.
- 쉬운 의심 방법: **아무것도 안 하는 기준선(`DummyClassifier`)과 먼저 비교한다.**

### 로지스틱 회귀와 결정 트리의 차이

| 로지스틱 회귀 | 결정 트리 |
|---|---|
| 계수와 절편을 학습 | 분할할 특성과 기준값을 학습 |
| 점수를 확률로 변환해 예측 | 조건을 따라 이동해 예측 |
| 결정 경계는 직선(평면) 하나 | 축에 평행한 사각형 영역 여러 개 |

## 3. 결정 트리의 학습과 예측

| 구분 | 하는 일 |
|---|---|
| 학습 (`fit`) | 훈련 데이터와 정답으로 분할 규칙(특성, 기준값)을 **만든다** |
| 예측 (`predict`) | 만든 규칙을 **따라** 리프까지 이동한다. 규칙은 바뀌지 않는다 |

```python
dt = DecisionTreeClassifier(random_state=42)
dt.fit(train_scaled, train_target)   # 훈련 0.9969, 테스트 0.8592 → 13.8%p 차이, 과대적합 징후
```

- 깊이 제한 없는 트리는 깊이 21, 리프 799개로 그림을 읽을 수 없을 만큼 복잡하다.
- `plot_tree(dt, max_depth=1, filled=True, feature_names=[...])`의 `max_depth`는 **그림의 표시 범위**만 제한한다. 학습 깊이를 제한하려면 모델에 `max_depth`를 준다.

### 트리 용어

| 용어 | 의미 |
|---|---|
| 루트 노드 | 트리의 시작점 (깊이 0) |
| 부모·자식 노드 | 분할 전과 후의 노드 |
| 가지 | 조건에 따라 이동하는 경로 (조건을 만족하면 왼쪽) |
| 리프 노드 | 최종 예측이 이루어지는 노드 |
| 깊이 | 루트부터 내려간 단계 수 |

### 루트 노드 읽기

```
sugar <= -0.239      ← 표준화된 당도 기준 (원단위 4.325)
gini = 0.367         ← 클래스가 섞인 정도
samples = 5197       ← 노드의 샘플 수
value = [1258, 3939] ← [레드, 화이트]
```

| 노드 | 샘플 | 레드 | 화이트 | 지니 |
|---|---|---|---|---|
| 부모 | 5,197 | 1,258 | 3,939 | 0.367 |
| 왼쪽 (당도 ≤ 4.325) | 2,922 | 1,177 | 1,745 | 0.481 |
| 오른쪽 (당도 > 4.325) | 2,275 | 81 | 2,194 | 0.069 |

- 표준화 기준값 −0.2391을 원단위로 되돌리면(× 표준편차 + 평균) 4.325다.
- 기준값은 훈련 데이터에서 이웃한 두 값의 **중간값**이다. 4.325, 1.625, 11.025처럼 끝자리가 5인 이유다.

### 리프에서 예측하기

```
새로운 데이터 → 분할 조건 확인 → 왼쪽·오른쪽 이동 → 리프 도착 → 클래스 분포로 예측
```

- 예측 클래스는 리프의 다수 클래스, 확률은 리프의 클래스 비율이다(예: 레드 8, 화이트 2 → 레드 0.8).
- KNN 확률이 "이웃 k개의 비율"이었다면 트리 확률은 "같은 리프에 모인 훈련 샘플의 비율"이다. 실제 정답일 가능성을 보증하지 않는다.
- 같은 리프에 도착한 데이터는 모두 같은 확률을 받는다. 당도가 2.0이든 4.0이든 리프 6에 도착하면 레드 0.6994다.

### 리프 확률을 얼마나 믿을 수 있나

리프 확률의 신뢰도는 리프에 모인 샘플 수에 달려 있다. 트리가 깊어지면 리프가 잘게 쪼개져 샘플 한두 개짜리 순수 리프가 늘고, 확률이 0이나 1로만 나온다. 테스트 세트 1,300개로 확인한 결과:

| 모델 | 테스트 정확도 | 확률 1.0으로 예측한 비율 | 확률 1.0인데 틀린 비율 |
|---|---|---|---|
| 트리 깊이 3 | 0.8415 | 0% | 0% |
| 트리 깊이 5 | 0.8608 | 1.5% | 0.1% |
| 트리 깊이 7 | 0.8631 | 37.2% | 1.1% |
| 트리 제한 없음 | 0.8592 | 99.4% | **13.7%** |

- 깊이 제한 없는 트리는 정확도는 괜찮지만, 테스트 샘플의 13.7%를 "100% 확신"하고 틀렸다.
- `max_depth` 제한은 정확도뿐 아니라 확률을 덜 극단적으로 만드는 데도 의미가 있다.

## 4. 분할 기준: 지니 불순도와 정보 이득

### 지니 불순도

$$G = 1 - (p_0^2 + p_1^2)$$

| 클래스 구성 | 지니 |
|---|---|
| 50 : 50 | 0.50 (이진 분류의 최댓값) |
| 90 : 10 | 0.18 |
| 100 : 0 | 0 (순수 노드) |

- 직관: 노드에서 샘플 하나를 뽑아 노드의 클래스 비율대로 무작위로 이름표를 붙였을 때 **틀릴 확률**이다.
- 루트: 1 − [(1258/5197)² + (3939/5197)²] ≈ 0.367

### 정보 이득

$$\text{정보 이득} = \text{부모 불순도} - \text{자식 노드의 가중평균 불순도}$$

- 가중평균: (2922/5197) × 0.481 + (2275/5197) × 0.069 ≈ 0.301
- 정보 이득: 0.367 − 0.301 ≈ 0.066

| 계산 방식 | 분할 후 불순도 | 정보 이득 |
|---|---|---|
| 단순 평균 | 0.275 | 0.092 (부풀려짐) |
| 가중평균 | 0.301 | 0.066 |

- 단순 평균은 샘플이 적은 노드를 같은 비중으로 쳐서 이득을 부풀린다. 샘플 1개만 떼어 내 순수 노드를 만드는 "꼼수 분할"을 가중평균이 걸러 낸다.
- 왼쪽 자식의 불순도는 부모보다 **높아졌지만** 가중평균이 줄었으므로 좋은 분할이다. 개별 노드가 아니라 **가중평균**으로 판단한다.

### 실습 A 결과

| 실습 | 부모 | 왼쪽 | 오른쪽 | 가중평균 | 정보 이득 |
|---|---|---|---|---|---|
| A-1, A-2 | 0.3669 | 0.4811 | 0.0687 | 0.3006 | **0.0664** |
| A-3 (부모와 같은 비율로 나눔) | 0.3669 | 0.3669 | 0.3670 | 0.3669 | **0.0000** (실제 4.3 × 10⁻⁹) |

- 데이터를 둘로 나눴다는 사실만으로는 이득이 생기지 않는다. 나눈 뒤 클래스가 얼마나 더 잘 구분되는지가 중요하다.

### 분할 후보를 찾는 방법과 한계

1. 각 노드에서 특성마다 정렬된 값의 중간값을 모두 기준값 후보로 삼는다.
2. 후보마다 정보 이득을 계산해 가장 큰 (특성, 기준값)을 고른다.
3. 자식 노드에서 같은 탐색을 반복한다.

- 이 방식은 **탐욕적 알고리즘**이다. 그 순간의 최선만 고르므로 전체적으로 최적인 트리라는 보장이 없다. 이 한계와 과대적합을 보완하는 것이 앙상블(5-3)이다.

### 엔트로피

$$H = -p_0 \log_2 p_0 - p_1 \log_2 p_1$$

| | 지니 | 엔트로피 |
|---|---|---|
| 설정 | `criterion='gini'` (기본값) | `criterion='entropy'` |
| 50 : 50 | 0.5 | 1 |
| 순수 노드 | 0 | 0 |

- 깊이 3에서 엔트로피로 바꿔도 테스트 정확도는 0.8415로 같았다. 중요도는 [0.087 0.891 0.022]로 조금 달랐다.

## 5. 트리 깊이와 가지치기 (교안 6장)

| 설정 | 훈련 | 테스트 | 차이 | 리프 수 |
|---|---|---|---|---|
| 깊이 제한 없음 | 0.9969 | 0.8592 | 13.8%p | 799 |
| `max_depth=3` | 0.8455 | 0.8415 | 0.4%p | 8 |

- 결정 트리는 분할을 반복할수록 복잡해지고, 결국 훈련 데이터를 거의 다 외운다.
- **가지치기**는 트리의 복잡도를 제한해 과대적합을 줄이는 방법이다.
- 학습할 때부터 성장을 제한하는 것이 **사전 가지치기**다. 다 키운 뒤 잘라 내는 사후 가지치기도 있다(scikit-learn의 `ccp_alpha`).
- 리프가 8개로 줄어 그림으로 읽을 수 있는 트리가 됐다.
- 점수 차이는 줄었지만 테스트 점수도 조금 내려갔다. **차이가 작다고 더 좋은 모델은 아니다.**
- 교안의 이 비교는 테스트 세트로 한 "관찰"이다. 실제 깊이 선택은 검증 세트·교차 검증으로 한다(이론 ④).

### 실습 B, B-3: 깊이별 복잡도

| 설정 | 실제 깊이 | 리프 수 | 훈련 정확도 |
|---|---|---|---|
| 1 | 1 | 2 | 0.7579 |
| 2 | 2 | 4 | 0.8099 |
| 3 | 3 | 8 | 0.8455 |
| 4 | 4 | 16 | 0.8572 |
| 5 | 5 | 31 | 0.8672 |
| 7 | 7 | 100 | 0.8896 |
| 제한 없음 | 21 | 799 | 0.9969 |

- 리프 수가 크게 늘어도 훈련 정확도 개선 폭은 작다. 리프 수는 깊이마다 반드시 두 배가 되지 않는다.
- 설정한 깊이까지 반드시 자라는 것은 아니다. 유효한 분할이 없으면 일찍 멈춘다.

## 6. 표준화와 해석 (교안 7장)

| | 로지스틱 회귀 | 결정 트리 |
|---|---|---|
| 특성값을 쓰는 방식 | 계수를 곱해서 더함 (z = w·x + b) | 기준값과 크기만 비교 (당도 ≤ 4.325?) |
| 단위가 다르면 | 계수와 경사 크기가 왜곡됨 → 표준화 필요 | 순서만 같으면 같은 분할 → 표준화 불필요 |

- 강의 표현으로는 "특징값으로 계산한 게 없다". 표준화 전후 성능이 같은 이유는 모델이 단순해서가 아니라, 표준화가 값의 순서를 바꾸지 않기 때문이다.
- 깊이 3에서는 표준화 트리와 원본 트리의 테스트 예측 1,300개가 모두 같았다.
- 다만 "항상 완전히 같다"는 아니다. 이득이 같은 후보 중 무엇을 고를지, 기준값의 부동소수점 계산 때문에 깊은 트리에서는 달라질 수 있다. 원본으로 학습한 제한 없는 트리는 테스트 0.8585로 표준화 트리(0.8592)와 한 샘플 차이가 났다.
- 원본으로 학습하면 `sugar <= 4.325`처럼 실제 단위로 규칙을 설명할 수 있다.

### 실습 C: 새로운 와인의 예측 경로

| 입력 | 경로 | 리프 | 리프 분포 (레드 / 화이트) | 예측 | 확률 |

| 알코올 10, 당도 3.0, pH 3.2 | 당도 ≤ 4.325 → 당도 > 1.625 → 알코올 ≤ 11.025 | 6 | 798 / 343 | 레드 | [0.6994 0.3006] |

## 7. 특성 중요도 (교안 8장)

```python
dt.feature_importances_   # [0.1235 0.8686 0.0079] → 알코올, 당도, pH, 합 1
```

- 각 특성이 분할에서 불순도를 줄인 기여의 상대적 비율이다.
- "당도만으로 87%를 맞혔다"도, "당도가 와인 종류의 원인이다"도 아니다.
- 주의할 점:
  - 값의 종류가 많은 연속형 특성일수록 분할 후보가 많아 중요도가 부풀려지기 쉽다.
  - 비슷한 정보를 담은 특성이 둘이면 중요도가 나뉘어 둘 다 낮게 보일 수 있다.
  - 실무에서는 순열 중요도(`sklearn.inspection.permutation_importance`)로 교차 확인하기도 한다.

## 8. 결정 트리를 꼼꼼히 배우는 이유 (강의 보충)

- 랜덤 포레스트와 XGBoost는 결정 트리를 수십, 수백 개 묶은 앙상블이다. 트리 하나의 원리(분할 기준, 불순도, 과대적합, 가지치기)를 알면 이 모델들을 훨씬 빨리 이해한다.
- 표 형태 데이터에는 트리 기반 앙상블이 강하고 가벼운 선택지로 많이 쓰이고, 이미지 분류에는 CNN 같은 딥러닝이 쓰인다.
- 트리 기반 모델이 표준화 없이 쓰이는 이유도 이번 장의 원리와 같다.

### 이번 장 핵심

| 개념 | 한 줄 |
|---|---|
| 학습 | 분할할 특성과 기준값을 학습 |
| 분할 기준 | 가중평균 불순도가 가장 많이 줄어드는(정보 이득이 큰) 조건 |
| 예측 | 조건을 따라 리프 도착 → 다수 클래스, 리프 비율이 확률 |
| 가지치기 | 복잡도를 제한해 과대적합 완화. 깊이는 검증으로 선택 |
| 표준화 | 필요 없음. 원본으로 학습하면 해석이 쉬움 |
| 특성 중요도 | 불순도 감소 기여의 상대적 비율. 정확도나 인과관계가 아님 |

## 9. 셀프 체크

20초 안에 이유까지 말할 수 있으면 통과.

1. `plot_tree(dt, max_depth=1)`을 실행하면 학습된 트리의 깊이가 바뀌나?
2. 루트 노드의 `value = [1258, 3939]`에서 지니 불순도 0.367은 어떻게 나오나?
3. 지니 불순도가 0.5인 경우와 0인 경우는?
4. 왼쪽 자식의 불순도(0.481)가 부모(0.367)보다 높은데 좋은 분할인 이유는?
5. A-3처럼 부모와 같은 비율로 나누면 정보 이득은 왜 0인가?
6. 깊이 3 트리의 테스트 정확도가 제한 없는 트리보다 낮은데도 가지치기를 하는 이유는?
7. 표준화 트리의 `sugar <= -0.239`와 원본 트리의 `sugar <= 4.325`는 어떤 관계인가?
8. 레드로 예측했는데 레드 확률이 0.6994인 이유는?

<details>
<summary>정답</summary>

1. 아니다. 그림의 표시 범위만 제한한다. 학습 깊이는 `DecisionTreeClassifier(max_depth=...)`로 정한다.
2. 1 − [(1258/5197)² + (3939/5197)²] ≈ 0.367
3. 두 클래스가 반반이면 0.5, 한 클래스만 있으면 0(순수 노드)이다.
4. 판단 기준은 샘플 수로 가중평균한 불순도(0.301)이고, 그 값이 부모보다 낮기 때문이다.
5. 두 자식의 클래스 비율이 부모와 같아서 가중평균 불순도가 부모와 같기 때문이다.
6. 훈련·테스트 점수 차이가 13.8%p에서 0.4%p로 줄어 과대적합이 완화되고, 트리가 단순해져 해석하기 쉽기 때문이다. 다만 반드시 더 좋은 모델은 아니며 깊이는 검증으로 고른다.
7. 같은 조건이다. −0.239를 원래 단위로 되돌리면(× 표준편차 + 평균) 4.325다.
8. 도착한 리프에 레드 798개와 화이트 343개가 함께 있어 798 / 1141 ≈ 0.6994이기 때문이다.

## 10. 헷갈리기 쉬운 내용과 정정

| 헷갈리기 쉬운 이해 | 정확한 내용 |
|---|---|
| Non-Null Count는 결측값의 개수 | 결측이 아닌 값의 개수. 전체 행 수와 같으면 결측 없음 |
| 과소적합은 정확도 하나로 판단하는 절대적 상태 | 도달 가능한 성능과 비교한 상대적 개념. 기준선·다른 모델·표현력 실험으로 확인 |
| `plot_tree`의 `max_depth`가 트리를 가지치기함 | 그림의 표시 범위만 제한. 학습 깊이는 모델에 설정 |
| 한쪽 자식의 불순도가 오르면 나쁜 분할 | 가중평균 불순도가 줄면 좋은 분할 |
| 표준화 트리와 원본 트리는 예측이 같을 수밖에 없음 | 이론상 같은 분할이지만, 동점 후보와 부동소수점 때문에 깊은 트리에서는 달라질 수 있음 |
| 훈련·테스트 차이 13.8% | 13.8%p (퍼센트포인트) |
| 표준화 전후 성능이 같은 것은 모델이 단순해서 | 트리가 값의 순서만 비교하고, 표준화는 순서를 바꾸지 않기 때문 |
