# Day 3 · 종합 정리

Nov 2, 2026 · @Lee Hyunwoo

오늘의 다섯 이론은 두 질문으로 묶인다. 정답 없이 데이터의 구조를 어떻게 찾을까(K-평균, PCA), 그리고 신경망은 어떻게 예측하고 그 예측을 어떻게 개선할까(다층 신경망, 손실과 기울기, 역전파).

이 문서는 Day 3 이론 1~5의 강의 메모와 교안을 정리하고, NumPy, scikit-learn 1.9.1, PyTorch 2.14.1로 직접 확인한 숫자를 한곳에 모은 것이다. 강사님이 기대한 것은 수식 해석보다 **각 방법이 무엇을 입력받고, 어떤 기준으로 학습하고, 무엇을 만들어 내는지 구별하는 것**이다.

## 방법별 비교

한 줄로 쓰면, 앞의 두 방법은 정답 없이 입력만 보고 구조를 요약하고, 신경망은 정답과의 차이(손실)를 줄이도록 학습한다.

| 방법 | 입력 | 정답(레이블) | 기준 | 출력 |
| --- | --- | --- | --- | --- |
| K-평균 | 샘플의 특성 | 없음 (비지도) | 가까운 중심에 배정, 그룹 평균으로 중심 갱신 | 클러스터 배정과 중심 |
| PCA | 샘플의 특성 | 없음 (비지도) | 분산이 가장 큰 방향 | 주성분 축과 그 위의 좌표 |
| 다층 신경망 순전파 | 입력 특성 | 필요 없음 (예측만) | 현재 가중치와 편향으로 계산 | 예측값(점수, 확률) |
| 신경망 학습 | 입력과 정답 | 있음 (지도) | 손실을 줄이는 방향 | 갱신된 가중치와 편향 |
| 역전파 | 손실과 순전파의 중간 값 | 손실 계산에 이미 반영 | 연쇄법칙 (국소적 미분의 곱) | 각 가중치와 편향의 기울기 |

역전파는 학습 방법이 아니라 기울기를 구하는 방법이다. 학습은 역전파로 구한 기울기를 경사 하강법으로 갱신에 쓰는 과정이다.

## 이론별 핵심과 직접 확인한 숫자

| 이론 | 핵심 | 확인한 숫자 |
| --- | --- | --- |
| 1. 비지도 학습과 K-평균 | 가까운 중심에 배정하고 그룹 평균으로 중심을 갱신하는 일을 반복한다. 클러스터 번호는 이름표일 뿐 과일 종류가 아니다 | 과일 300장을 112 / 98 / 90장으로 나눔, 다수 과일과 288장(96%) 일치 |
| 2. 주성분 분석 | 분산이 큰 방향으로 새 축을 만들고 앞쪽 축의 좌표만 남긴다. 설명된 분산 92%는 정확도가 아니다 | 주성분 50개로 분산 92.1%, 파이프라인 정확도 99.67% (2개 98.67%, 1개 77.33%) |
| 3. 퍼셉트론에서 다층 신경망까지 | 가중합과 편향에 활성화 함수를 층마다 반복한다. 비선형이 없으면 층이 하나의 선형 계산으로 합쳐진다 | XOR: 최적의 선형 모델은 네 점 모두 0.5, 비선형 2층은 성공 |
| 4. 신경망 학습과 기울기 계산 | 손실을 줄이는 방향으로 가중치와 편향을 갱신한다. 기울기 계산과 매개변수 갱신은 다른 단계다 | 손실은 처음부터 줄지만 정확도는 갱신 5번까지 46%, 10번에서 37%로 하락 |
| 5. 계산 그래프와 오차역전파법 | 노드마다 전달받은 기울기에 국소적 미분을 곱해 뒤에서 앞으로 전달한다 | 가중치 기울기 -4, 편향 기울기 -2, 한 번 갱신하면 손실 2 → 0.5 |

자세한 내용은 각 이론의 Docs와 노트를 본다. 이 문서의 숫자는 모두 로컬 실행 결과이고, 이론 5 교안에서는 8.6절 본문의 편향 기울기 부호 하나(2가 아니라 -2)만 틀렸다.

## 이론을 가로지르는 연결

**정답 없이 구조 찾기 (이론 1, 2).** 둘 다 `fit(X)`처럼 입력만 쓴다. K-평균은 샘플을 묶어 행을 요약하고, PCA는 특성을 합쳐 열을 줄인다. 주성분 2개로 돌린 K-평균은 300장을 110 / 99 / 91장으로 나눠 다수 과일과 290장이 일치했다. 다만 시드 하나의 결과이고 PCA가 군집을 개선한다는 근거는 아니다.

**손실로 학습하기 (이론 3, 4, 5).** 신경망은 예측과 정답의 차이를 손실 하나로 나타내고, 손실을 줄이는 방향(기울기의 반대)으로 가중치와 편향을 바꾼다. 정확도는 작은 변화에 값이 변하지 않아 기울기가 0인 구간이 많아서 학습 기준으로 쓰지 않는다. 학습은 손실로, 최종 평가는 목적에 맞는 지표로 따로 본다.

**이전 날과의 연결.** Day 2의 로지스틱 회귀에서 은닉층을 빼면 이론 3의 다중 분류 신경망과 같다. 신경망은 그 앞에 은닉층을 넣어 점수를 계산할 특성까지 스스로 학습한다. 이론 4에서 손으로 쓴 역전파의 시작값 `y - t`가 이론 5에서 노드 단위로 설명된다.

**계산량.** 수치 미분은 파라미터마다 순전파를 두 번 해서 계산량이 파라미터 수에 비례한다. 앞서 측정한 은닉 너비 2048(파라미터 약 582만 개)에서 수치 미분은 약 18,491초(어림), 순전파 + 역전파는 4.89ms였다. 역전파가 빠른 것은 뒤쪽에서 구한 값을 앞 층이 재사용해 중복 계산이 없어지기 때문이다. 시간은 실행 환경에 따라 다르다.

## 헷갈리기 쉬운 내용과 스스로 확인할 질문

| 헷갈리기 쉬운 이해 | 정확한 내용 |
| --- | --- |
| 훈련 데이터 없이 fit한다 (K-평균) | 훈련 데이터는 있고 정답 레이블이 없다 |
| 클러스터 번호는 과일 종류다 | 그룹 이름표이고 시드에 따라 바뀐다 |
| 분산 92%이면 정확도도 92%다 | 입력의 변동을 남긴 비율이지 정확도가 아니다 |
| 중요한 주성분은 분류에도 중요하다 | 중요하다는 것은 분산이 크다는 뜻이다 |
| 층을 쌓으면 항상 표현력이 늘어난다 | 비선형 활성화 함수가 있어야 늘어난다 |
| 은닉층의 시그모이드 출력은 확률이다 | 다음 층으로 넘기는 중간 값이다 |
| 정확도로 학습하지 않으니 정확도는 안 본다 | 학습은 손실로, 평가는 목적 지표로 따로 본다 |
| 기울기가 0이면 최소다 | 최소, 최대, 안장점 모두 기울기가 0이다 |
| 수치 미분과 경사 하강법은 같은 층위다 | 기울기 계산 방법과 그 기울기로 갱신하는 방법이다 |
| 곱셈 노드는 자기 값을 곱한다 | 다른 쪽 입력값을 곱한다 |
| 시작 기울기 1은 최종 결과가 1이라는 뜻이다 | 자기 자신으로 미분한 값이고 순전파 결과는 그대로다 |
