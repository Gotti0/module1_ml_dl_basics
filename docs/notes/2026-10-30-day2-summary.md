## 2. 이론별 핵심과 실습 결과

### ① 로지스틱 회귀

```
입력 특성 → 점수 z (계수 × 특성 + 절편) → 확률 (시그모이드 / 소프트맥스) → 클래스
```

| 실습 | 확인한 결과 |
|---|---|
| A. 시그모이드 | z = −2 / 0 / 2 → 0.1192 / 0.5 / 0.8808 |
| B. 무게 ±1 | 빙어 확률 0.982 / 0.973 / 0.960, 예측은 계속 Smelt |
| C. 점수 배율 | 최고 확률 0.842 → 0.225로 떨어져도 예측은 계속 Perch |

- z는 확률이 아니라 로그 오즈다. 계수는 z에 선형으로, 확률에는 비선형으로 작용한다.
- 다중 분류는 argmax로 고르므로 최고 확률이 0.5 미만이어도 예측할 수 있다.
- 예측 클래스(`predict`)와 예측 확률(`predict_proba`)은 다른 정보다. 확률 열 순서는 `classes_`를 본다.

### ② 확률적 경사 하강법

$$\theta \leftarrow \theta - \eta \cdot \frac{\partial L}{\partial \theta}$$

| 실습 | 확인한 결과 |
|---|---|
| A. 로지스틱 손실 | 정답 확률 0.9 / 0.6 / 0.1 → 손실 0.105 / 0.511 / 2.303 |
| B. 한 번의 갱신 | w, b: 0 → 0.05, 확률 0.5 → 0.525, 손실 0.6931 → 0.6444 |
| C. `partial_fit` | 계수는 바뀌지만 정확도는 내려갈 수도 있음 |
| 8장. 검증 세트로 에포크 선택 | 100 에포크 선택, 최종 테스트 0.925 |

- 경사는 방향, 학습률은 보폭이다. 로지스틱 손실은 볼록이라 지역 최적해가 없다.
- 오래 학습한다고 검증 성능이 계속 좋아지지 않는다.

### ③ 결정 트리

| 실습 | 확인한 결과 |
|---|---|
| A. 정보 이득 | 부모 0.3669, 가중평균 0.3006, 정보 이득 0.0664 |
| B. 깊이별 복잡도 | 제한 없음: 깊이 21, 리프 799, 훈련 0.9969 |
| C. 새 와인 예측 | 당도 3.0 → 레드 0.6994 (리프 798 / 343), 당도 6.0 → 화이트 0.9483 |

| 설정 | 훈련 | 테스트 |
|---|---|---|
| 깊이 제한 없음 | 99.69% | 85.92% |
| 최대 깊이 3 | 84.55% | 84.15% |

- 판단은 개별 노드가 아니라 샘플 수로 가중평균한 불순도로 한다.
- 표준화가 필요 없다. 특성 중요도는 상대적 기여도이고 인과관계가 아니다.
- 리프 확률은 리프 샘플 수에 따라 신뢰도가 달라진다. 제한 없는 트리는 테스트의 13.7%를 확률 1.0으로 틀렸다.

### ④ 교차 검증과 하이퍼파라미터 탐색

| 실습 | 확인한 결과 |
|---|---|
| A. 깊이 선택 | 검증 1위는 깊이 5 (0.8578). 깊이 4 이상은 0.853~0.858로 비슷 |
| B. 그리드 서치 분석 | 1·2위 차이 0.0004, 표준편차의 20분의 1 |

| 탐색 | 조합 | 교차 검증 학습 | 최고 평균 검증 |
|---|---|---|---|
| 다중 그리드 서치 | 1,350 | 6,750번 | 0.8684 |
| 랜덤 서치 | 100 | 500번 | 0.8695 |

- 교차 검증은 성능을 높이는 방법이 아니라 설정을 평가하는 방법이다.
- 탐색으로 고른 `max_depth`(14, 39)는 실제 깊이(10, 12)가 아니었다. 다른 하이퍼파라미터가 먼저 성장을 막았다.
- 정답 한 점이 아니라 괜찮은 범위를 찾는다. 실무에서는 랜덤 서치로 감을 잡고 그리드 서치로 좁힌다.

## 3. 실험 결과를 해석할 때 확인할 것

| 관찰 | 판단 |
|---|---|
| 훈련 정확도가 매우 높다 | 검증 정확도도 높은지 확인 |
| 훈련·검증 점수 차이가 작다 | 두 점수 자체가 충분히 높은지 확인 (기준선과 비교) |
| 더 오래 학습했다 | 검증 성능이 계속 개선되는지 확인 |
| 트리를 더 깊게 만들었다 | 복잡도 증가가 일반화 성능으로 이어졌는지 확인 |
| 한 모델이 검증 1위다 | 같은 평가 조건인지, 점수 차이가 변동보다 큰지 확인 |

- 강의에서 반복한 태도: **확신 말고 의심하기.** 결과를 보고 가설을 세우고, 다른 실험으로 확인한다.
- 예: 로지스틱 회귀(78%)의 과소적합 의심 → 기준선(75.8%)·다항 특성·트리와 비교해 상대적 과소적합으로 확인.

## 4. 모델 개발 과정

```
문제 정의 및 데이터 준비 (info, describe, 결측값)
          ↓
훈련·테스트 데이터 분리
          ↓
후보 모델 학습
          ↓
교차 검증으로 모델·설정 비교
          ↓
검증 결과를 근거로 선택
          ↓
전체 훈련 데이터로 재학습
          ↓

          ↓
배포 후 모니터링과 재학습 (MLOps)
```

- 테스트 점수로 고르면 서비스에서 성능이 엉망이 될 수 있다. 테스트 점수는 약속이 아니라 추정이다(37/40 = 0.925의 95% 신뢰구간 약 0.80~0.97).
- 모델러는 개발에서 끝나지 않는다.

## 5. 이론 ⑤ 트리의 앙상블 (미진행, 예습용)

원본 정리본은 4-4 뒤에 `5. 트리의 앙상블` 제목과 5-1·5-2(랜덤 포레스트, 엑스트라 트리)가 빠진 채 이어져 있었다. 아래는 그 구조를 복원해 정리한 것이다.

### 5-1. 랜덤 포레스트와 OOB

- 부트스트랩 샘플로 트리를 여러 개 학습하고 예측을 결합한다.
- OOB 평가: 각 샘플을 학습하지 않은 트리들의 예측으로 그 샘플을 평가한다. OOB 정확도 0.8934.

### 5-2. 엑스트라 트리

- 분할 기준값을 무작위로 정한다. 무작위 기준값을 쓰더라도 후보를 평가하고 그중 좋은 분할을 고른다.

### 5-3. 그레이디언트 부스팅

```
현재 누적 예측 → 손실을 줄이는 방향 계산 → 새 트리 학습 → 학습률만큼 반영 → 누적 예측 갱신
```

- 랜덤 포레스트가 트리들의 예측을 평균한다면, 부스팅은 누적 예측을 개선하는 트리를 하나씩 추가한다.
- 기본 설정 → 트리 500개·학습률 0.2: 훈련 0.888 → 0.946, 검증 0.872 → 0.878. 트리를 늘려도 일반화 성능이 같은 비율로 좋아지지 않는다.

### 5-4. 히스토그램 기반 부스팅, XGBoost, LightGBM

| 모델 | 특징 |
|---|---|
| 히스토그램 기반 부스팅 | 연속값을 구간(bin)으로 묶어 분할 탐색을 효율화 |
| XGBoost | 손실의 미분 정보와 복잡도 페널티를 함께 고려 |
| LightGBM | 구간 기반 분할, 개선 효과가 큰 리프부터 확장 |

- LightGBM의 리프 중심 성장은 트리 하나 안에서 다음에 나눌 리프를 고르는 방법이다. 트리를 순서대로 추가하는 부스팅 원리와 구분한다.

### 5-5. 모델별 평균 교차 검증 정확도

| 모델 | 정리본 (교재) | 로컬 실행 |
|---|---|---|
| 랜덤 포레스트 | 89.05% | 89.05% |
| 엑스트라 트리 | 88.88% | 88.88% |
| 그레이디언트 부스팅 기본 | 87.20% | 87.20% |
| 그레이디언트 부스팅 설정 변경 | 87.80% | 87.80% |
| 히스토그램 기반 부스팅 | 88.01% | 87.94% |
| XGBoost | 87.82% | 87.84% |
| LightGBM | 88.01% | 88.01% |

- 히스토그램 기반 부스팅과 XGBoost는 라이브러리 버전 차이로 소수 둘째 자리가 다르다. 순위 해석은 같다.
- 이 데이터와 기본 설정에서의 결과이며, 튜닝하지 않았으므로 알고리즘 순위로 해석하지 않는다.

### 5-6. 순열 중요도

- 학습된 모델은 그대로 두고 특성 하나의 값만 샘플 사이에서 섞어, 성능이 얼마나 떨어지는지 본다.
- 히스토그램 기반 부스팅, 테스트 세트 기준: 알코올 0.054, **당도 0.200**, pH 0.047. 모델이 당도에 가장 많이 의존한다. 원인이라는 뜻은 아니다.

## 6. 오늘의 핵심 질문

| 번호 | 질문 | 답 |
|---|---|---|
| ① | 이진 로지스틱 회귀에서 점수를 확률로 바꾸는 함수는? | 시그모이드 |
| ② | 클래스별 확률의 합을 1로 만드는 함수는? | 소프트맥스 |
| ③ | 예측이 얼마나 잘못되었는지 계산하는 것은? | 손실 함수 |
| ④ | 계수와 절편을 수정할 방향을 알려 주는 것은? | 경사 |
| ⑤ | `SGDClassifier`에서 학습을 이어 가는 메서드는? | `partial_fit()` |
| ⑥ | 결정 트리가 좋은 분할을 고르는 기준은? | 정보 이득 |
| ⑦ | 새 샘플이 최종적으로 도착하는 노드는? | 리프 노드 |
| ⑧ | 모델과 하이퍼파라미터를 고를 때 쓰는 데이터는? | 검증 데이터 |
| ⑨ | 지정한 모든 조합을 비교하는 탐색 방법은? | 그리드 서치 |
| ⑩ | 누적 예측을 보완하는 트리를 순서대로 추가하는 방법은? (예습) | 그레이디언트 부스팅 |

### 반드시 기억할 세 가지

1. **예측과 학습은 다르다.** 예측은 입력으로 결과를 만들고, 학습은 파라미터나 분할 규칙을 정한다.
2. **훈련 성능과 일반화 성능은 다르다.** 모델 선택은 검증 결과로 한다.
3. **복잡할수록 좋은 것이 아니다.** 깊이, 에포크, 트리 수를 늘리는 것보다 왜 그 설정을 골랐는지 설명할 근거가 중요하다.

## 7. 오늘의 자기 점검

### 잘한 점

- 핵심 구분(z는 확률이 아님, 학습과 예측의 차이, 가중평균 불순도)을 스스로 정리했다.
- 원리의 경계를 묻는 질문을 했다: 입력에서 z까지는 독립 모델인가, 작은 학습률과 지역 최적해, 과소적합은 상대적인가 절대적인가.

### 반복해서 나온 실수

| 패턴 | 장면 | 대책 |
|---|---|---|
| 전처리 기준을 어느 데이터에 fit하는지 | "각각 표준화", "fit은 val까지" | fit은 학습용 데이터에만, 나머지는 transform만 |
| 단계별 역할 섞기 | 시그모이드가 판정, 폴드마다 최적 조합 | 각 단계의 입력과 출력을 따로 떼어 보기 |
| 딥러닝 지식을 단순한 모델에 적용 | 지역 최적해, 작은 무작위 초기화 | "이 모델에도 해당하나?" 한 번 더 확인 |
| 숫자 받아 적기 | 계수 −0.04045, 0.00004 | 코드로 한 번 돌려 보기 |

### 강사님께 할 질문 (준비)
